# 預備功能：公司標準參數模板管理介面

## 狀態
預備開發

## 目標
將目前以 JSON 維護的公司標準參數模板，改為可由 GUI 編輯、審核與保存。

## 初步範圍
- 顯示現有模板：common、FP、PLB、PWR、ELV、LTG 等。
- 新增 / 修改 / 刪除 SC_ 參數欄位。
- 設定參數層級：型別 / 實例。
- 設定資料型別：文字、整數、數字等。
- 設定是否必填。
- 設定適用系統。
- 儲存後供族群歸檔與專案回收流程套用。

## 暫不處理
- 自動判斷所有族群應套用哪些非 SC_ 原生參數。
- 強制改寫既有正式庫所有族群。

## 備註
此功能排在「REVIT 點位大量放置外掛」雛形之後。
