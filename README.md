# SC REVIT

SC REVIT 是 Revit 2024 的 MEP 輔助工具集，提供消防支管、CAD 點位放置、排水接管及模型檢查功能。

## 下載與安裝

[下載 SC REVIT v0.6.0 一鍵安裝／更新包](https://github.com/NicheSam/SC-REVIT/releases/download/v0.6.0/SC_REVIT_v0.6.0_installer.zip)

1. 關閉 Revit 2024 與所有 SC REVIT 視窗。
2. 完整解壓縮下載的 ZIP。
3. 執行 `Install_SC_REVIT.bat`。
4. 安裝完成後重新開啟 Revit，在 Ribbon 找到 `SC 族群工具`。

同一個安裝包可用於首次安裝與覆蓋更新。請勿使用 GitHub 自動產生的 `Source code` 壓縮檔安裝。

## 消防支管操作教學

消防支管功能以同一份「拓樸計畫」控制畫面預覽與 Revit 建模，避免預覽判斷與正式建立採用不同結果。

### 1. 讀取主管與專案設定

1. 在 Revit 選取消防主管後開啟 `消防支管建立`。
2. 工具會自動載入系統類型、管類型、樓層與可用管徑。
3. 按 `讀取選取主管`，確認主管 ID、系統與管徑。
4. 選擇支管系統、管類型、樓層，並輸入 `支管距離樓層高度(cm)`。

### 2. 選取撒水頭

1. 回到 Revit 框選或多選要連接的撒水頭。
2. 按 `讀取框選撒水頭`。
3. 檢查清單中的 ID、族群、類型與座標。撒水頭位置不會被工具移動。

### 3. 分析 CAD 與拓樸

按 `分析並顯示預覽` 後，工具會：

- 讀取目前視圖中可見且已對位的 CAD 路徑。
- 依「管徑文字 → 線段顏色 → 圖層備援」判斷管徑。
- 依 CAD 幾何建立支管交點、T 接、四通、管徑分段與異徑位置。
- 將水平支管接到固定位置的撒水頭，垂直末段管徑依實際 Connector 需求處理。

分析結果中的待確認項目可雙擊定位。按 `查看路網圖` 可縮放、拖曳並核對主管、支管方向、管徑、異徑與管件配置。

```mermaid
flowchart LR
    A[選取主管] --> B[選取撒水頭]
    B --> C[讀取可見 CAD]
    C --> D[建立唯一拓樸計畫]
    D --> E[SVG 路網核對]
    E --> F[建立前完整檢查]
    F --> G[正式建立]
    G --> H[連通性與管徑驗證]
```

### 4. 檢查與正式建立

1. 先執行 `建立前完整檢查（完成後自動復原）`。這一步會實際驗證建模，但不在模型留下管線。
2. 確認結果後按 `正式建立消防支管`。
3. 若只有部分節點失敗，中文結果視窗會列出問題與影響範圍，可選擇保留成功部分或全部復原。
4. 保留成功部分後，仍可使用 Revit Undo 回復本次操作。

### 目前限制

- CAD 管徑模式需要目前視圖中有可見且已正確對位的 CAD 連結。
- 不同專案的撒水頭 Connector、系統分類、Pipe Type 與 Routing Preferences 可能不同，應先執行建立前完整檢查。
- L／U／雙 L 型複合主管、直接編輯 SVG 拓樸及自動避梁仍在規劃中，尚未列入本版正式功能。
- 無 CAD 底圖的統一管徑舊版模式仍在規劃中，本版尚未提供獨立頁籤。

後續規劃請參閱 [消防支管複合主管、拓樸修正與自動避梁計畫草案](docs/fire_branch_compound_routing_and_beam_avoidance_plan.md)。

## CAD 點位放置

- 自動檢查 CAD 與 Revit 座標及單位，避免點位落在模型數公里外。
- 預覽使用暫存顯示，不將預覽線當作正式模型資料。
- 重新預覽、完成、取消或關閉工具時，背景會清除 SC REVIT 建立的預覽元素及未使用群組類型。
- 清理只處理 SC REVIT 自己建立的資料，不影響使用者既有模型群組。

## 排水接入幹管

完整圖文請參閱：

- [Markdown 操作手冊](docs/SC_REVIT_drainage_operation_manual.md)
- [PDF 操作手冊](docs/SC_REVIT_drainage_operation_manual.pdf)
- [HTML 圖文版](docs/SC_REVIT_v0.5.0_drainage_user_guide.html)

最短操作流程：

1. 先在 `管件設定` 選擇目標 Pipe Type、System Type、管件、管徑及坡度。
2. 執行 `排水接入幹管`。
3. 依提示先選設備接口或開放支管端，再選本支要接入的主管。
4. 單支失敗只回復該支；完成後按 `Esc` 結束整輪操作。

## 常見問題

### 看不到 Ribbon

- 確認使用 Revit 2024。
- 關閉 Revit 後重新執行 `Install_SC_REVIT.bat`。
- 重新啟動 Revit；DLL 更新不能在已開啟的 Revit 中熱更新。

### 工具沒有讀到資料

- CAD 功能需要目前模型與視圖中存在可見的 CAD Link／DWG。
- 管線功能需要依畫面提示先選取對應的 pipe、設備或撒水頭。
- 若 GUI 顯示 Revit 尚未連線，先回到 Revit 完成選取，再重試該動作。

### 需要回報問題

關閉 Revit 後，執行安裝目錄中的 `收集_SC_REVIT_診斷資料.bat`，將桌面產生的診斷 ZIP 交給開發者。診斷資料會分開保存摘要、完整輸入、拓樸計畫與建立結果，避免重要內容被摘要截斷。
