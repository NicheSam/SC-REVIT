# 消防支管複合主管、拓樸修正與自動避梁計畫草案

## 狀態

- 狀態：草案，尚未實作
- 日期：2026-08-17
- 適用範圍：SC REVIT 消防支管建立
- 原則：拓樸計畫是 SVG 預覽與 Revit 建模的唯一共同來源

## 已確認決策

1. 主管可能是直線、L 型、U 型或雙 L 型，也可能包含彎頭與主管異徑。
2. 使用者選取一段主管作為搜尋種子；外掛沿實際 Connector 與管件展開主管路網。
3. 支管先依接入主管段的局部方向產生候選，再以 CAD 路徑圖確認完整複合路徑。
4. SVG 將升級為受限制的拓樸計畫編輯介面，只允許小幅且可驗證的修正。
5. 高度設定維持目前流程：保留「支管距離樓層高度」與既有高度基準，不改由主管中心高度換算。
6. 自動避梁延用 SC REVIT 開孔定位的 Link 座標與結構碰撞基礎，並參考 Issue #99 的 `review_required` 分流原則。
7. 本草案不改變灑水頭位置；灑水頭位置是固定端點。

## 目標流程

```text
選取主管種子
  → 建立 MainRunGraph
  → 讀取撒水頭與可見 CAD
  → 建立 CAD Route Graph
  → 產生多組支管候選
  → 管徑與管件判定
  → 產生 TopologyPlan
  → SVG 檢查／小幅修正
  → 結構障礙與避梁檢查
  → 產生 ExecutionPlan
  → Revit 沙盒建立與驗證
  → 正式建立
```

## 第一階段：複合主管路網

### MainRunGraph

每一段主管記錄：

- Pipe ElementId、起點、終點、局部方向及中心高度。
- Pipe Type、System Type、管徑及工作集等識別。
- 上下游 Connector 與相鄰彎頭、直接、異徑、三通或四通。
- 來源是使用者直接選取，或由主管種子自動延伸取得。

### 展開及停止規則

- 沿同系統且實際連通的 Pipe／Fitting 展開。
- 彎頭、直接與主管沿線異徑可以繼續。
- 遇到設備或灑水頭停止。
- 遇到三通或四通時，依主管連續性、管徑與方向判斷主管出口；其他出口列為支管候選。
- 多條路徑同樣合理時不得猜測，改標記為主管方向待確認。
- 不以固定角度或固定管徑作為唯一主管判定條件。

## 第二階段：CAD 複合支管路徑

### CAD Route Graph

將目前可見且已完成 Revit 座標轉換的 CAD 路徑整理為圖：

- 節點：線段端點、交點、轉折點、主管接入點與灑水頭端點。
- 邊：CAD 線段幾何、圖層、顏色、鄰近文字及管徑證據。
- 方向：沿用 Revit 視圖的東西南北，不為 SVG 排版任意旋轉。

### 候選選擇

- 從每一個合理主管接入點產生局部垂直接出候選。
- 後續路徑沿 CAD Route Graph 搜尋，可包含一個或多個轉折。
- 評分包含 CAD 重合度、路徑長度、轉折數、管徑證據、拓樸完整性及障礙風險。
- 幾何距離最近不等於最終選擇；距離相近且證據衝突時標記待確認。

## 第三階段：TopologyPlan 與 SVG 編輯

SVG 不直接保存建模資料，只顯示 TopologyPlan。所有修改都必須先寫入計畫，再重新產生 SVG 與 ExecutionPlan。

允許的修正：

- 在已計算的替代 CAD 路徑間切換。
- 修改單一管段管徑。
- 選擇合法的三通、四通、彎頭、直接或異徑意圖。
- 修改異徑前後管徑及同一管段內的合法放置位置。
- 修正支管的主管接入段。
- 合併或分離誤判的鄰近交點。

限制：

- 管徑只能從目前 Pipe Type 允許的尺寸中選擇。
- 管件只能從目前 Routing Preferences 可用的配置中選擇。
- 三支管線交點不能直接指定為四通。
- 每次修改後重新驗證方向、連通、管徑順序、管件空間及計畫雜湊。
- 若修改改變主管路徑、整排支管或多個相鄰交點，應重新分析，不以大量人工修改掩蓋演算法問題。

## 第四階段：高度設定

本草案不修改目前高度算法與 GUI：

- 保留「支管距離樓層高度」。
- 保留目前的管上端、管中心與管下端高度基準。
- 預覽與正式建模必須共用同一高度輸入及換算結果。
- 灑水頭位置不移動，垂管由水平支管接到實際灑水頭 Connector。

## 第五階段：自動避梁

### 可延用的開孔定位能力

- Revit Link 與 `GetTotalTransform()` 座標轉換。
- 梁、柱、牆及樓板 Solid 讀取。
- BoundingBox 粗篩。
- 路徑與 Solid 交集、Host ElementId 與碰撞位置。

開孔定位輸出的是穿越候選；自動避梁還必須增加自由空間搜尋與替代路徑產生，兩者不能視為同一功能。

### 共用模組

```text
StructuralObstacleQuery
  ├─ 開孔定位：碰撞 → 開孔候選
  └─ 消防支管：碰撞 → 避梁候選
```

### 避梁判定

檢查範圍不能只使用管中心線，必須包含：

- 管外半徑。
- 保溫厚度。
- 專案要求的施工淨距。
- 彎頭、異徑及接頭需要的實際安裝空間。

替代路徑可包含上繞、下繞與側繞，但允許方向、淨距、最大升降量及彎頭偏好必須由專案規則提供，不使用全專案固定數字。

### Issue #99 邊界

Issue #99 的結論保留：梁穿越屬於 `review_required`，不能因幾何掃描成功就自動開孔或自動建模。第一版避梁只產生候選與預覽，不直接修改模型。

## 實作順序與驗收

1. **主管路網唯讀分析**：L／U／雙 L 主管能由單一種子展開，且不誤納支管。
2. **CAD 複合路徑預覽**：路徑轉折、交點及方向與 CAD／Revit 視圖一致。
3. **TopologyPlan v4**：SVG 與 ExecutionPlan 使用同一份路徑、管徑與管件配置。
4. **SVG 小幅修正**：修改可追蹤、可復原，且每次都重新驗證。
5. **障礙唯讀分析**：以計畫路徑及實際淨空包絡找出梁碰撞。
6. **單支管避梁候選**：先在一支管與一支梁上比較候選，不正式建模。
7. **Revit 沙盒**：建立後驗證 Connector、系統、管徑、異徑方向、異常長度及完整回復。
8. **整批路網**：單支管通過後才擴大，不以使用者反覆測試取代沙盒驗證。

## 尚待工程確認

- 各專案允許上繞、下繞或側繞的範圍。
- 梁與管線的施工淨距及保溫厚度來源。
- 2×45° 與 2×90° 的優先順序。
- 允許的最大升降量、天花高度及其他禁入空間。
- 主管經三通／四通時的自動延伸停止規則。
