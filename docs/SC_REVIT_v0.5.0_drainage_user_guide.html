1. 安裝與開始

  1. 完整關閉 Revit 2024。
  2. 解壓縮 SC_REVIT_v0.5.0-drainage-dev_installer.zip。
  3. 執行 Install_SC_REVIT.bat，等待安裝完成。
  4. 重新開啟 Revit 2024，確認 Ribbon 出現 SC 族群工具 頁籤與 排水系統 面板。
  5. 第一次使用先開啟測試模型，完成管件設定後再執行接管。

2. Ribbon 圖示與功能

排水面板分成兩個 split button：日常建模使用「排水接入幹管」，局部整理使用「管中心對齊」下拉工具。

排水接入幹管

先選設備接口或開放管端，再明確選取本支要接入的主管。建立管段、彎頭、斜 T／Y 後立即驗證。

管件設定

依 Pipe Type 與 System Type 設定斜 T、Y、45°彎頭、變徑、坡度、管徑範圍與最短直管。

管中心對齊

先選高程基準管，再連續選取要對齊的管段。只調整中心線高程，不會把管段接入基準管。

45度對接

選取兩個開放管端，以一段 45°斜管與兩個 45°彎頭連接。兩端高程與位置必須有可行幾何。

向下45°

選來源，再選主管；只有求解結果確實為單 45°路徑時才建立，不會自動改成其他路型。

垂直向下

選取要延伸的開放管端，再選高程基準管；建立到基準管局部中心線高程的垂直管段，但不接入基準管。

其他 SC REVIT 面板

同一套圖示系統也套用到其餘 Ribbon 命令，顏色與符號分別表示資料、建模、檢查及修復動作。

3. 第一次使用：建立管件設定

  1. 展開「排水接入幹管」，按「管件設定」。
  2. 上方先選目標 Pipe Type 與 System Type，再按「新增設定列」。
  3. 確認 Profile 類型為 GravityDrainage。
  4. 依專案族群指定斜 T 三通、Y 三通、立管轉水平彎頭、45°／錯層彎頭與變徑。
  5. 設定支管坡度、適用管徑與最短直管。此開發版測試基準為 1%。
  6. 需要放寬來源系統或 FlowDirection 時，使用「進階來源規則」。
  7. 按「儲存設定」。不合格的 connector、角度或尺寸設定會被拒絕。
欄位用途常見問題
目標 System Type／管類型決定這列設定適用的主管與新建管段。選錯類型會得到 PROFILE_NOT_MATCHED。
斜 T／Y切入主管時使用的 junction。尺寸或 connector 角度不符時不得建立。
45°／錯層彎頭來源轉向、平面轉向與不同高程補正。takeout 過大可能導致最短直管不足。
變徑主管管徑大於支管時使用。族群需覆蓋實際主、支管尺寸。
支管坡度控制重力排水支管沿流向下降。目前坡度同步仍在調整，建立後必須抽查。

4. 排水接入幹管：日常操作流程

  1. 按「排水接入幹管」。
  2. 依提示 1/2 點選設備接口或任意開放管端。Pipe 有兩個開放端時，點選位置會影響 connector 判斷。
  3. 依提示 2/2 明確點選本支要接入的主管。系統不再自行替你挑選遠處的主管。
  4. 外掛依 Profile、尺寸、方向、坡度、最短直管與管件 takeout 規劃路徑。
  5. 成功後可直接點選下一支；單支失敗會顯示原因，確認後仍可繼續。
  6. 按 Esc 結束整輪命令。成功結果會合併成一次 Revit Undo。

立管接入的預期拓撲

立管不應直接拉一條長斜線到主管。預期路型為：來源垂直段、來源側雙 45°高程補正、徑向支管、平面 45°轉向、最後以斜 T／Y 接入主管。徑向段與最後接入段依 Profile 套用坡度。

建立後必查

  • 支管沿排水方向是否持續下降，沒有局部倒坡。
  • 立管來源側是否為雙 45°，不是 90°直角。
  • 斜 T／Y 支口是否朝主管下游。
  • 主管大於支管時，變徑是否使用正確尺寸與方向。
  • 所有 fitting 是否真正接上 connector，沒有孤立短管。

5. 修復工具何時使用

工具選取順序適合情境不會做的事
管中心對齊基準管 → 要調整的管段，可連續選取設備延伸管或無坡管需要先對齊局部中心線高程。不建立接管、不套用完整路由。
45度對接較高開放端 → 較低開放端兩段既有管可以用一段 45°斜管橋接。不切入主管、不自動選第三支管。
向下45°來源 → 目標主管幾何明確且只需要單 45°接入。若求解不是 single_45，會拒絕建立。
垂直向下開放管端 → 高程基準管先建立到指定局部高程的垂直延伸。不把垂直管接到基準管。

6. 常見失敗與排查

訊息代表意思處理方式
PROFILE_NOT_MATCHED來源 connector 與目標主管沒有相符設定。回到管件設定檢查 Pipe Type、System Type、管徑與來源規則。
SOURCE_BELOW_TARGET_MAIN來源接點低於主管局部中心線，重力排水不能向上接入。重新檢查高程或選取其他主管；不要強制反坡。
NO_FEASIBLE_ROUTE角度、takeout、坡度或最短直管無法同時成立。增加距離、調整來源位置、確認管件尺寸，或先使用修復工具整理幾何。
PLANNED_PIPE_TANGENT_TOO_SHORT扣除彎頭與 junction takeout 後沒有足夠直管。拉開來源與主管距離，或換用 takeout 較小且經驗證的管件。
SIGNED_SLOPE_INVALID支管沒有形成設定坡度，或排水方向相反。檢查主管下游方向、來源高程與 Profile 坡度。
安全行為：單支失敗時該支 Transaction 會回復，不應留下切斷主管、孤立 fitting 或半成品短管。

7. 測試模型驗收清單

  • 同徑與 100×80 變徑各測一支。
  • 垂直、水平與傾斜開放管端各測一支。
  • 至少一支立管驗證來源側雙 45°與平面 45°接入。
  • 至少一支故意使用不匹配 Profile，確認模型沒有被修改。
  • 量測每段實際坡度；目前 1% 為測試基準，但仍須人工抽查。
  • 完成五支後測試一次 Undo 是否能復原整輪操作。
