## 發現的分析問題

### M2 修正說明（2026-08-17）

- CAD 圖面可以把同一條實體路徑拆成多個線段；線段長度不要求與 Revit 管段相等，長度只保留作診斷。
- 路徑幾何必須和 issue100 點位放置使用同一條座標鏈：Block／CAD 幾何 → Block Transform → `ImportInstance.GetTotalTransform()` → Revit 模型座標。
- 已新增唯讀 `cad_route_graph`：保留碎片來源、圖層、顏色，將容許範圍內的端點合併，將真正交叉切成節點；超出容許範圍的空隙保留為斷線證據，不自動補線。
- 目前 6/110 的舊版單段投影比對只作基線，不再作為 CAD 不吻合或禁止建模的單一門檻；修正後 DLL 重新載入才能重跑活動模型證據。


M1 的同徑路徑切割器在無邊界循環／回到起點時，曾把同一個 PipeId 重複放進候選路徑，造成 DN25 出現首尾重複的假路徑。已修正為遇到起點或已走過的 PipeId 就停止追加，並新增回歸測試；現在 211 項 Python 測試通過，重新輸出的 profile 中重複 PipeId 候選為 0。
