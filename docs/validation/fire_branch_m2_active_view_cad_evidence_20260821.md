## 已修改的來源選擇規則

`CadPathShadowVerifier.ReadVisibleCadPathSources` 現在依序處理：

1. 只從活動視圖的 `FilteredElementCollector(doc, activeView.Id)` 取得 ImportInstance。
2. 若存在活動視圖擁有的 CAD（`OwnerViewId == activeView.Id`），只使用這批，不讓其他視圖的 DWG 參與。
3. 若沒有視圖專屬 CAD，只有在可見的全模型 CAD 恰好唯一一個時才使用；多個全模型 CAD 直接視為沒有可安全選定的來源，不合併猜測。
4. SVG 與後續拓樸判斷仍共用同一份 CAD 抽取結果；本次沒有修改建模器或灑水頭垂管連接邏輯。

同時新增契約測試，防止未來恢復「掃描所有 CAD」或合併多個全模型 CAD 的做法。
