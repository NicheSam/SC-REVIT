## 不要誤判的地方

1. 目前 Revit 選取數為 0；本報告列出的 ID 是模型盤點結果，不是某次 GUI 尚未送出的選取集合。
2. CAD「可讀」不等於 CAD「已配對」。目前只證明 ImportInstance、座標轉換、線段與圖層存在。
3. M2 幾何模型「連得起來」不等於 Revit 系統「連得起來」。M2 的 Connector Count=0 已明確指出這個證據缺口。
4. 報告沒有修改 DLL，也沒有修改或部署模型元素；BIM Agent 執行記錄為唯讀，建立／刪除／修改數量均為 0。
