# SC REVIT v0.7.0 使用說明

## 安裝與更新

1. 關閉 Revit 2024 與所有 SC REVIT 視窗。
2. 從 GitHub Releases 下載並完整解壓縮 `SC_REVIT_v0.7.0_installer.zip`。
3. 執行 `Install_SC_REVIT.bat`。
4. 完成後重新開啟 Revit 2024，在 Ribbon 找到 `SC 族群工具`。

同一個安裝包可用於首次安裝及覆蓋更新。DLL 無法在已開啟的 Revit 中熱更新。

## 消防支管建立

### 使用前確認

- 目前視圖中的 CAD Link 可見且已正確對位。
- 主管、撒水頭、System Type、Pipe Type 及管件 Routing Preferences 已設定。
- 建議先在模型副本或小範圍執行。

### 操作步驟

1. 在 Revit 選取一段屬於目標消防主管網路的管線。
2. 開啟 `消防支管建立`，確認工具已自動載入專案資料。
3. 按 `讀取選取主管`，核對主管 ID、系統及管徑。
4. 在 Revit 框選需要連接的撒水頭，再按 `讀取框選撒水頭`。
5. 設定支管系統、管類型、管徑、樓層及 `支管距離樓層高度(cm)`。
6. 按 `分析並顯示預覽`。
7. 開啟路網圖，核對主管方向、支管路徑、各段管徑、異徑及三通／四通。
8. 執行 `建立前完整檢查（完成後自動復原）`。
9. 檢查通過後，按 `正式建立消防支管`。

### 系統如何決定路徑

- CAD 幾何先建立主管與支管 Route Graph。
- 撒水頭會產生水平及垂直的接管候選。
- 若可能連到多條主管，以 CAD 路徑實際連通證據為最高優先。
- 管徑依「文字 → 線段顏色 → 圖層備援」判定。
- 同一份拓樸計畫同時提供 SVG 顯示及 Revit 建模使用。

### 如何閱讀路網圖

- 實線表示已有 CAD 路徑證據的計畫管段。
- 虛線或 `CAD 路徑未驗證` 表示證據不足，正式建立前應先確認。
- 線條顏色與粗細用於區分 CAD 顏色及管徑。
- 橙色管件表示異徑或需要注意的接點。
- 路網圖採 Revit 視圖的東、西、南、北方位，不應自行旋轉成魚骨示意方向。

### 部分建立成功

局部三通或管件被 Revit 拒絕時，工具不會自動刪除全部成功結果。視窗會提供：

- `保留成功部分`：保留已建立元素，仍可用一次 Revit Undo 復原。
- `全部復原`：取消本次建立的全部元素。

詳細資料會分開顯示主要管件錯誤及其下游受影響灑水頭。幾何看似相接不代表 MEP Connector 已連通，仍應以最終連通檢查為準。

## CAD 點位放置

1. 在目前視圖確認 CAD Link 可見。
2. 開啟點位放置工具並選擇目標族群。
3. 產生螢光預覽，確認座標及範圍。
4. 完成放置或關閉工具後，SC REVIT 會清理自己的暫存預覽元素。

## 問題回報

關閉 Revit 後執行安裝目錄中的 `收集_SC_REVIT_診斷資料.bat`。診斷 ZIP 會保存摘要、完整輸入、拓樸計畫及建立結果，供追查實際失敗接點。
