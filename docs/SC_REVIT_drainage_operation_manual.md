版本基準：`main` / `snapshot-676ce995fd74`
適用環境：Autodesk Revit 2024
文件狀態：開發預覽版，應先使用測試模型驗證

> 本手冊只描述目前 Git 原始碼實際顯示在 Ribbon 上、可由使用者操作的功能。舊版手冊中的「45度對接」、「向下45°」與「垂直向下」目前不在 Ribbon 上，不應視為本版標準操作。

## 2. 使用前條件

開始建模前，確認：

- 使用可寫入的 Revit 2024 專案，不是唯讀模型。
- 來源為 Pipe，或具有 `DomainPiping + ConnectorType.End` 的 FamilyInstance。
- 要使用的來源 connector 是開放、圓形且可讀取管徑。
- 目標主管是 Pipe，並由使用者在第 2 步明確點選。
- 專案已載入要使用的斜 T／Y、45°彎頭與變徑族群。
- 管件設定中有符合目標 Pipe Type、System Type、來源規則及支管管徑的設定列。
- 主管有可判斷的下游方向。水平且沒有坡度或連接證據的主管可能被拒絕，避免斜 T／Y 方向放反。

## 3. 第一次使用：管件設定

### 3.1 建立設定列

1. 展開 `排水接入幹管`。
2. 按 `管件設定`。
3. 在視窗上方選擇目標 Pipe Type 與 System Type。
4. 按 `新增設定列`。
5. 檢查系統自動帶入的 Routing Preference 管件。
6. 完成下面各欄後按 `儲存設定`。

### 3.2 設定欄位

| 欄位 | 用途 | 本版預設／限制 |
| --- | --- | --- |
| Profile 類型 | 決定路由策略 | 目前只支援 `GravityDrainage`。 |
| 目標 System Type | 限定要接入的主管系統 | 必須與使用者點選的主管相符。 |
| 管類型 | 決定主管與新建管段使用的 Pipe Type | 同一管型、系統與 Profile 只能有一列。 |
| 斜 T 三通／Y 三通 | 切入主管的 junction | 實際 connector 角度、尺寸與可用性會在儲存及建立時檢查。 |
| 立管轉水平彎頭 | 立管出口轉向使用 | 必須覆蓋實際支管尺寸。 |
| 45°／錯層彎頭 | 單 45°、雙 45°與不同高程路由使用 | takeout 會計入最短直管計算。 |
| 變徑 | 主管大於支管時使用 | 族群必須包含實際主、支管尺寸。 |
| 支管坡度 (%) | 套用於需要設計坡度的重力支管段 | 預設 1%；允許 0.1% 至 10%。 |
| 最小／最大管徑 | 限定設定列適用的來源管徑 | 預設 25 mm 至 300 mm。 |
| 最短直管 | 扣除 fitting takeout 後仍須保留的直管 | 預設 80 mm。 |
| 進階來源規則 | 限定來源系統與 FlowDirection | `Bidirectional`、無法判定方向預設允許；`In` 預設拒絕。 |

`顯示全部管配件` 只改變下拉清單的顯示範圍，不代表每個顯示出的管件都能通過角度、connector 與尺寸驗證。

設定存入 Revit 專案的 DataStorage。模型移交時設定會隨 RVT 移動。

## 4. 排水接入幹管

### 4.1 正確選取順序

1. 按 `排水接入幹管`。
2. 提示 `1/2` 時，點選設備接口或任意開放管端。
3. 如果物件有多個開放 connector，請靠近真正要接管的端點點選。
4. 提示 `2/2` 時，明確點選本支要接入的主管。
5. 系統依 Profile、管徑、來源軸向、高程、主管下游方向、管件 takeout、最短直管及既有管件淨距求解。
6. 成功後直接點選下一支來源，再點選該支主管。
7. 按 `Esc` 結束整輪操作。

本版不會只選來源後自動猜測主管；每一支都固定使用「來源 → 主管」兩步選取。

### 4.2 建立與 Undo 行為

- 每支接管使用獨立 Transaction。
- 單支失敗時，該支會回復，不應留下被切斷的主管、孤立 fitting 或半成品短管。
- 失敗視窗關閉後可繼續下一支。
- 同一輪成功建立的支管會合併為一次 Revit Undo。
- 如果整輪沒有任何成功支管，整個 TransactionGroup 會回復。

### 4.3 系統會嘗試的路型

路型由幾何與管件條件自動選擇，使用者不需要另外按路型按鈕：

| 路型 | 適用情境 |
| --- | --- |
| 軸向直接接入 | 來源軸向可以直接到達主管 junction。 |
| 不同高程斜接 | 來源高於主管，可使用向主管下降的斜向轉接吸收高差。 |
| 單 45° | 一個 45°轉向即可滿足來源方向與主管接入。 |
| 雙 45° | 需要兩個 45°彎頭形成偏移或方向補正。 |
| 立管平面轉向 | 立管先保留垂直段，再以來源側 45°轉折、支管與主管 junction 完成接入。 |
| 末端雙 45° | 立管或不同高程情境的備援路型。 |

### 4.4 本版可解析的來源

- 垂直、水平或傾斜 Pipe 的開放端。
- 衛生設備及其他 FamilyInstance 的開放 piping connector。
- 同徑接管。
- 主管大於支管的變徑接管，但必須配置可用變徑。
- 來源高於主管的不同高程接管，只要路徑能持續向主管下降。

### 4.5 硬性拒絕條件

- 來源 connector 低於主管局部中心線，需要向上回流。
- 找不到相符的 `GravityDrainage` Profile。
- 來源 connector 已連接、不是圓形 piping end connector，或管徑無法讀取。
- 主管下游方向無法可靠判斷。
- junction 位置碰到主管既有 fitting 或必要淨距。
- 所選主管管段太短，斜 T／Y 會超出可用範圍。
- 45°彎頭、junction takeout 與最短直管無法同時容納。
- 建立後坡度、junction 方向或 connector 拓撲驗證失敗。

## 5. 坡度與不同高程

排水方向的底層規則是：越接近主管越低，越離開主管越高。

- 設定列的坡度控制需要設計坡度的支管段，預設為 1%。
- 不同高程的斜向轉接段可由實際幾何形成其他下降角度，不要求所有斜段都是 1%。
- 來源低於主管時不會用任意斜率硬接，系統會拒絕。
- 主管本身有坡度時，接入高程以候選接點的局部主管中心線高程計算，不以主管端點的單一高程代替。
- 既有整段管網的暫時去坡、編輯後恢復坡度，尚不是本版 Ribbon 功能。

建立完成後仍應抽查：

- 支管沿流向沒有局部倒坡。
- junction 支口朝主管下游。
- 主管大於支管時，變徑方向與尺寸正確。
- 兩端 connector 真正連接，沒有視覺上靠近但拓撲未接的斷點。

## 6. 管中心對齊

### 6.1 操作

1. 按 `管中心對齊`。
2. 提示 `1/2` 時，點選非垂直的高程基準管。
3. 提示 `2/2` 時，點選要調整的管段。
4. 可連續點選多支目標管。
5. 按 `Esc` 結束；成功修改合併為一次 Undo。

### 6.2 實際邊界

- 沒有高程差上限。
- 基準管不可為垂直管。
- 目標管若兩端都未連接，整支管會做垂直平移。
- 目標管若只有一端已連接，已連接端保持固定，只調整另一端。
- 目標管若兩端都已連接，系統拒絕修改，避免拉扯既有系統。
- 已釘選或位於群組中的目標管不會修改。
- 高程取自基準管在目標平面位置的局部中心線，因此可配合有坡度的基準管。
- 此命令不建立支管、不切入主管，也不自動套用完整排水路由。

## 7. 失敗訊息怎麼看

視窗最上方是可讀的失敗原因與處理方式；最下方的英文代碼是提供除錯使用。

| 視窗標題／代碼 | 意思 | 優先處理 |
| --- | --- | --- |
| 找不到適用的管件設定 / `PROFILE_NOT_MATCHED` | 主管管型、系統、來源規則或管徑沒有匹配設定列 | 回到管件設定檢查 Pipe Type、System Type、管徑範圍及管件。 |
| 無法判斷主管流向 / `MAIN_DOWNSTREAM_UNRESOLVED` | 主管沒有足夠坡度或連接證據判斷下游 | 改選流向明確的主管，或先建立可辨識的坡度／連接關係。 |
| 支管低於主管 / `SOURCE_BELOW_TARGET_MAIN` | 重力路徑需要向上回流 | 提高來源、降低主管或改選較低主管。 |
| 主管既有管件會與新接頭衝突 | 新 junction 落入既有 fitting 的安裝淨距 | 改選相鄰主管管段或移動既有管件。 |
| 所選主管管段長度不足 | junction 超出這一段主管的可用範圍 | 選較長的相鄰管段；這不等同支管距離太近。 |
| 管件安裝空間不足 / `TANGENT_TOO_SHORT` | takeout 後沒有足夠直管 | 增加間距、避開主管端點或改用可用尺寸的管件。 |
| 目前位置沒有合格接管路徑 / `NO_FEASIBLE_ROUTE` | 方向、高程、最短直管與管件空間無法同時成立 | 調整來源位置／高程或改選主管接入位置。 |
| 無法安全調整支管長度 | 延長開放端會破壞另一端既有連接 | 確認點選端確實開放，並檢查另一端設備或 fitting。 |
| 排水坡度不成立 | 建立後未通過設定坡度或沿流向下降檢查 | 檢查來源、主管局部高程及設定坡度。 |
| 主管接頭方向不正確 | 斜 T／Y 支口方向未通過下游檢查 | 檢查主管流向與設定的 junction 族群。 |

若視窗顯示「模型已回復到操作前狀態」，先不要手動保留畫面中的預覽線；記下來源 ID 與技術代碼再重試。

## 8. 測試模型驗收

### 8.1 每次更新後的驗收項目

- 垂直、水平、傾斜開放管端各一支。
- FamilyInstance piping connector 一支。
- 同徑及主管大於支管的變徑各一支。
- 同高程與不同高程各一支。
- 一支故意使用不匹配 Profile，確認模型沒有被修改。
- junction 支口朝主管下游。
- 各段 connector、坡度及最短直管成立。
- 連續成功數支後，一次 Undo 可復原整輪操作。

## 9. 版本邊界

本手冊對應 `snapshot-676ce995fd74` 的排水功能基準。後續實驗中的「斜 T 支口向上旋轉 45°，搭配兩個 45°彎頭」新優先路型不包含在此版本，也不應出現在本手冊的正常操作結果中。

目前仍屬開發預覽版。正式專案批次使用前，必須先以實際 Pipe Type、System Type、管件族群及管徑在測試模型完成驗收。
