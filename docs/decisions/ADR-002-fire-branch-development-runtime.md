# ADR-002：消防支管的測試模式與背景規則更新

## 狀態

採用

## 日期

2026-08-12

## 背景

消防支管仍在開發 CAD 路徑判斷、拓樸與變徑規則。若每次規則調整都重開
Revit，測試速度太慢；但 Revit API 又不能在外部程式直接修改模型，也不能安全地
任意更換已載入的 DLL。

## 決定

- 使用同一個消防支管 GUI，不另開第二套使用者工具。
- 操作分成「分析並顯示預覽」、「測試建立（完成後自動復原）」與「正式建立」三段。
- CAD 與路徑分析放在獨立背景程序。每次分析重新啟動，因此修改 Python 規則後，
  下一次分析就會使用新版本，不必重開 Revit。
- Revit 建模仍由固定 DLL 執行。測試模式會真的建立管線、管件並進行連接驗證，
  驗證完成後回復整個交易群組，不保留測試元件。
- 只有測試模式通過後，GUI 才開放正式建立。重新讀取選取、建立失敗或正式建立
  完成後，必須重新分析與測試。
- Revit API 呼叫方式、交易結構或 DLL 介面改變時，仍需重建 DLL 並重開 Revit；
  只有背景分析規則屬於熱更新範圍。

## 影響

- 使用者在開發期間仍有完整 GUI，不需要操作命令列。
- 多數 CAD 判斷與規則調整可以立即重測。
- 測試模式能驗證真實 Revit 連接結果，同時避免污染正式模型。
- GUI 會用簡單中文呈現結果；批次、規則識別與錯誤細節收在「技術資訊」。
